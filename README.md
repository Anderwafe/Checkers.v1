# Building
## Prerequisites
1. QT sdk
2. QMake
3. Make
4. C++ compiler
5. C compiler (?)

## Building from sources
1. Download sources from github
```shell
git clone https://github.com/Anderwafe/Checkers.v1.git
```
2. Create `Makefile`
```shell
qmake Checkers.pro
```
3. Build source code
```shell
make
```
4. Play!
```shell
./Checkers
```
